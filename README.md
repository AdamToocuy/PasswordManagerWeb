Введение
Веб приложение ExchangeRates создан для отслеживания курсов валют,
а также для быстрой конвертации из одной валюты в другую. Имеет такие функции как:
Конвертер валют, Курсы валют с возможностью выбора базовой валюты и целевой валюты и выбором 
временного промежутка. Страница, отвечающая за курсы, выводит минимальное значение и максимального.
